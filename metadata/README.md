# Generated metadata

All files in this directory that determine RNA-seq selection/pairing are
generated by:

```bash
Rscript scripts/00_build_geo_patient_metadata.R
```

There is no manually maintained SRA run list, disease/normal mapping, pairing
override, or clinical override.

## `sra_runs.csv`

Generated schema:

```text
run_accession,cohort,gsm,patient_id,condition,library_layout,
fastq_1,fastq_2,md5_1,md5_2
```

The `fastq_*` and `md5_*` fields are taken from ENA `read_run` metadata.  Thus
`scripts/02_run_kallisto.sh` downloads the exact files selected by the metadata
builder instead of reconstructing an FTP path from the run accession.

The file includes all screened libraries needed by Table 1.  For GSE40419 this
includes the unmatched/unclassified screened runs; they are intentionally not
put into the matched-patient sample sheet.

## `sample_sheet_GSE*.csv`

Generated schema:

```text
library_id,patient_id,condition,directory
```

Every retained patient appears exactly once as `normal` and once as `disease`.
Pairing is reconstructed from public sample titles/metadata:

- GSE244679: `[patientN]` vs `[patientD]`
- GSE127165: `ANM_<subject>` vs `LSCC_<subject>`
- GSE144269: `pat <n> non-tumor` vs `pat <n> tumor`
- GSE40419: `LC_*_nor` vs matching `LC_*`, after the ERP001058 direct-FASTQ
  screening described in the top-level README

## `metadata_output/GEO_patient_metadata_combined.tsv`

This is the single clinical source for `R/04_clinical_association.R`.
Generated columns include:

```text
GSE, cohort, disease_name, patient_id,
normal_gsm, disease_gsm, normal_title, disease_title,
normal_run_accession, disease_run_accession,
PASI, age, age_of_onset, stage, alcohol, smoking, sex,
orphan_delta
```

GEO sample characteristics provide the available cohort metadata.  GSE127165
age is additionally retrieved automatically from the primary publication's
public Additional file 1, Table S1.  If that table cannot be downloaded/parsing
does not recover every RNA-sequenced subject in strict mode, reconstruction
stops rather than imputing values.

`R/04_clinical_association.R` aligns patient-level statistics to this table by
`normal_run_accession`, reproducing the accession-based matching used in the
analysis.

## Audit outputs

The builder also writes:

```text
metadata_output/GEO_sample_metadata_long.tsv
metadata_output/GEO_SRA_run_mapping.tsv
metadata_output/FASTQ_selection_audit.tsv
metadata_output/ERP001058_read_run.tsv
metadata_output/GSE40419_excluded_libraries.tsv
metadata_output/GSE127165_supplement_clinical.tsv
metadata_output/public_source_provenance.tsv
```

These files are intended to make every automatic decision inspectable.

## Optional `orphan_delta_input.tsv`

This is retained only for compatibility with an earlier local metadata table.
If present, `orphan_delta` is joined by cohort + normal run accession (or
patient ID).  It does not determine FASTQ selection, disease/normal status, or
patient pairing and is not required by the manuscript clinical models.
